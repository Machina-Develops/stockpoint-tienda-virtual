# 📦 StockPoint – Tienda Virtual

## 📝 Descripción
StockPoint es una plataforma web desarrollada en **WordPress** que ofrece diferentes planes de gestión de stock para pequeños y medianos comercios.  
Su propósito es brindar una solución simple, clara y accesible que permita a los negocios **controlar su inventario en tiempo real**, organizar procesos y tomar decisiones con información confiable.

---

## 🛠️ Instalación y Uso
1. Instalar **XAMPP** (incluye Apache y MySQL).  
2. Copiar los archivos del proyecto en la carpeta `htdocs`.  
3. Iniciar Apache y MySQL desde el panel de XAMPP.  
4. Importar la base de datos desde `phpMyAdmin` con el archivo `stockpoint.sql`.  
5. Abrir en el navegador:  
   ```
   http://localhost/stockpoint
   ```

---

## 📋 Requisitos y Tecnologías Utilizadas
- **Requisitos previos:**
  - XAMPP o similar (Apache + MySQL + PHP)

- **Tecnologías:**
